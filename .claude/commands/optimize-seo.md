Perform an SEO audit and optimization for a page:

1. Ask me which page to optimize

2. Review and check for:

   **Meta Tags:**
   - Title tag (50-60 characters, includes target keyword)
   - Meta description (150-160 characters, compelling copy)
   - Open Graph tags (og:title, og:description, og:image, og:url)
   - Twitter Card tags
   - Canonical URL

   **Content SEO:**
   - One H1 tag with primary keyword
   - H2-H6 hierarchy is logical
   - Keywords used naturally in content
   - Content length appropriate for topic
   - Internal linking opportunities
   - External links (if any) open in new tab

   **Technical SEO:**
   - Semantic HTML structure
   - Image alt attributes
   - Proper URL structure
   - Mobile responsive
   - Page load performance
   - Schema.org structured data (JSON-LD)

   **Target Keywords:**
   For Rocket Feast, prioritize:
   - "QR Ordering System Thailand"
   - "Restaurant POS Software"
   - "Hospitality Management System"
   - "Restaurant Operations Software"
   - "F&B Management Platform"

3. Provide:
   - SEO score (out of 100)
   - List of issues with severity
   - Specific recommendations with code examples
   - Suggested improvements to content
   - Structured data recommendations

4. Generate optimized metadata code ready to implement

Focus on Thailand/SEA market in Phase 1, with consideration for global expansion in Phase 2.
