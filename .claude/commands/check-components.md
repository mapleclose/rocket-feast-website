Help me find the right Untitled UI component for my needs:

1. Ask me what I'm trying to build or what functionality I need

2. Search through the following component directories:
   - `src/components/base/` - Basic UI elements
   - `src/components/application/` - Complex application components
   - `src/components/marketing/` - Marketing-specific components
   - `src/components/foundations/` - Icons, logos, design elements

3. List all relevant components with:
   - Component name and file path
   - Brief description of what it does
   - Key props/features
   - Example usage if available

4. If multiple components could work, explain the differences and recommend the best fit

5. If no existing component fits, suggest which components could be combined to achieve the desired result

This helps ensure we're using existing components before creating new ones, maintaining consistency and reducing code duplication.
